# YukiKotoba Backend

REST API untuk aplikasi YukiKotoba, dibangun dengan [NestJS](https://nestjs.com/) mengikuti pola MVC (Module, Controller, Service, Entity, DTO).

## Menjalankan

```bash
cd backend
npm install
npm run start:dev
```

Server berjalan di `http://localhost:3001`.

## Perintah Lainnya

```bash
npm run lint    # memeriksa kualitas kode
npm run test    # menjalankan unit test (Vitest)
npm run build   # build produksi ke folder dist/
```
